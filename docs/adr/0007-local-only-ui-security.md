# ADR-0007: UI는 127.0.0.1 전용, Host 검사와 `X-Lab` 헤더로 보호

- 상태: 채택 · 2026-10-13

## 맥락
`lab ui`는 에이전트를 실행하고(셸 권한), `.env`를 고쳐요. 브라우저의 다른 탭이나 악성 페이지가 이 서버를 조종하면 안 돼요.

## 결정
- 서버는 `127.0.0.1`에만 바인딩해요.
- `Host` 헤더가 `127.0.0.1` 또는 `localhost`가 아니면 거부해요. DNS rebinding을 막는 장치예요.
- 상태를 바꾸는 요청은 모두 POST이고 `X-Lab: 1` 헤더가 있어야 해요. 다른 사이트는 CORS preflight 없이 커스텀 헤더를 붙일 수 없고, 서버는 preflight를 승인하지 않아요. 이게 CSRF 방어예요.
- `lab view`는 읽기 전용이에요. POST, 설정, 세션, 실행을 모두 막아요.
- 경로 파라미터는 `[\w.-]+`만 받고 `.`과 `..`는 거부해요. 파일 경로는 resolve한 뒤 작업 폴더 안에 있는지 확인해요.

## 고려한 대안
DSH Web처럼 토큰 URL로 인증하는 방식도 있어요. 하지만 로컬 1인 도구라서 Host 검사와 헤더만으로 충분하다고 봤어요. 외부에 열 계획이 생기면 다시 봐요.

## 결과
- 좋은 점: 로그인 없이 바로 열려요.
- 감수한 점: 같은 컴퓨터의 다른 로컬 프로세스는 막지 못해요. 절대로 `0.0.0.0`에 바인딩하지 않아요.
