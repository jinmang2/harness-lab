# ADR-0001: 결정은 ADR로 남긴다

- 상태: 채택 · 2026-10-13

## 맥락
설계 이유가 대화와 `docs/DESIGN.md`에 흩어져 있어요. 어떤 도구를 왜 쓰고 왜 안 썼는지(LangGraph, LangChain, Langfuse 등)를 몇 주 뒤에는 잊기 쉬워요.

## 결정
`docs/adr/`에 결정마다 파일 하나를 둬요. `DESIGN.md`는 "지금 구조가 어떤가"를, ADR은 "왜 그렇게 정했나"를 맡아요.

## 결과
- 결정을 바꿀 때 근거를 다시 찾을 필요가 없어요.
- ADR을 쓰는 비용이 들어요. 되돌리기 어려운 것, 대안이 있었던 것만 써요.
