# ADR-0009: 비밀값은 쓰기 전용, 에이전트 셸에서는 뺀다

- 상태: 채택 · 2026-10-13

## 맥락
UI에서 API 키를 넣게 되면서, 키가 브라우저, trace, 내보내기 zip, gateway body, 외부 트레이서로 새어 나갈 길이 생겼어요.

## 결정
- 키는 `.env`(gitignore, 권한 600)에만 저장해요. 서버는 키 값을 브라우저로 보내지 않고 `{configured, source}`만 보내요. DSH의 credentials 화면과 같은 방식이에요.
- 설정 값은 한 줄의 출력 가능한 문자만 받아요. 줄바꿈 계열 문자와 제어 문자는 거부해요. `.env`에 변수를 심는 주입을 막기 위해서예요.
- 에이전트 셸에는 이름에 `KEY`, `PASSWORD`, `SECRET`, `TOKEN`이 들어간 환경변수를 넘기지 않아요. DSH의 `scrubbedParentEnv`와 같은 규칙이에요.
- gateway는 `Authorization` 헤더를 기록하지 않아요.

## 결과
- 좋은 점: 에이전트가 `env`를 실행해도 키가 화면과 로그에 찍히지 않아요.
- 감수한 점: 샌드박스가 아니라서 에이전트가 `.env` 파일을 직접 읽는 것까지는 막지 못해요.
